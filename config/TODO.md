# Planning for v0.5.0

v0.4.0 delivered one complete end-to-end mission and closed the gameplay,
asset, audio and CI work. The remaining item from the original nine is the
SDL 2.0 port, which 0.4.0 deliberately prepared for rather than attempted.

## Core Goal
- Port the platform layer to SDL 2.0 (#11). `src/platform_sdl12.c` is the only
  file in the tree that calls SDL, so this is a backend swap: add
  `src/platform_sdl2.c` and select it at build time.

## Why this is smaller than it looks
On Ubuntu 24.04 and newer, `libsdl1.2-dev` is `sdl12-compat`, which already
reimplements the SDL 1.2 API on top of SDL2 — `sdl-config --version` reports
1.2.72 where real SDL 1.2 ended at 1.2.15, and `./pro` links `libSDL2` and
`libSDL3`. The game is therefore already running on SDL2 through a translation
layer. The port removes that layer rather than changing platform.

## Sequenced work
1. **Make the platform types opaque.** `include/platform.h` still typedefs
   `plat_surface` to `SDL_Surface` and so on. SDL2 has no `SDL_Surface`-based
   blit-to-screen model, so these need to become handles before the backend can
   change. This is the only part that touches files outside `platform_*.c`.
2. **Add `src/platform_sdl2.c`** implementing the same header over
   `SDL_Window`/`SDL_Renderer`/`SDL_Texture`, with a makefile switch. Keep the
   1.2 backend until the CI matrix is green on both.
3. **Convert the music to OGG.** SDL_mixer 1.2's MP3 decoder reads past its own
   buffer (see the README). The code already prefers `assets/audio/music.ogg`,
   so this is an asset change with no code change — and it is what lets
   `make asan` run with music loaded, which in turn lets CI run it.
4. **Wire `make asan` into CI** once step 3 removes the third-party fault.
5. **Promote the physics drivers into `tests/`.** `src/collision.c` and
   `src/enemy.c` need no window or event loop, and ad-hoc drivers against them
   found both Slice 6 bugs. Making them permanent is the cheapest real test
   suite this project can have.

## Deferred, not forgotten
- **Per-state resource loading.** `load_game_resources()` still loads every
  asset for every state up front and `cleanup_game()` frees them in one place.
  Fine at this size; wrong once there are several levels.
- **A level format.** Level 1's geometry is hardcoded in
  `load_game_resources()`. Levels 2 and 3 need data, not more constants —
  `Niv2.png` and `Niv3.png` are already in the repository.
- **Replace the placeholder art.** Everything generated by
  `scripts/gen_placeholder_assets.py` is sized to `assets/MANIFEST.tsv` and can
  be swapped 1:1 for hand-drawn work. `make verify` enforces the dimensions.
- **Decide what to do with the 24 unreferenced assets** that `make verify`
  lists, including the tic-tac-toe art left behind by the deleted minigame.
- **The `perso` struct still mixes physics and render state**, and `image[2][9]`
  is declared where only `[2][7]` is filled.
- **`initPerso` and `initPerso1` remain near-duplicates**, differing only in
  spawn x and health-bar directory.
