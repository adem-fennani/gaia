# Gaia

A 2D local-co-op platformer in C, built on SDL 1.2. Two players share one
screen and must both reach the exit beacon to complete the mission.

## Current state

v0.4.0 delivers one complete end-to-end mission: menu → level → result →
menu, with real collision, a patrolling enemy, working audio, and CI.

**The art is placeholder.** Level geometry, obstacles, the goal beacon, the
enemy, the minimap and the HUD health bars are generated by
`scripts/gen_placeholder_assets.py` at the exact sizes the renderer needs. They
are meant to be replaced 1:1 by hand-drawn PNGs of the same dimensions —
`assets/MANIFEST.tsv` records the contract and `make verify` enforces it.

### Known issues

- **SDL_mixer's MP3 decoder overruns its buffer.** Not our bug: SDL_mixer
  1.2.12 dates from 2012 and is unmaintained. AddressSanitizer catches an
  8464-byte read starting 1024 bytes past a 72112-byte allocation, inside
  `mad_getSamples` → `SDL_ConvertAudio` on the mixer's audio thread. This is
  the most likely cause of the audio noise and instability reported on modern
  Linux. The fix is to ship the music as OGG, which uses the maintained
  `libvorbisfile` path instead:

  ```bash
  ffmpeg -i assets/audio/music.mp3 -c:a libvorbis -q:a 4 assets/audio/music.ogg
  ```

  The game prefers `music.ogg` and falls back to `music.mp3`, so dropping that
  file in fixes it with no code change. Until then the MP3 path is used and is
  known-bad rather than supported.

- **SDL 1.2 is not really SDL 1.2 on current distros.** On Ubuntu 24.04 and
  newer, `libsdl1.2-dev` is `sdl12-compat`, which reimplements the SDL 1.2 API
  on top of SDL2 — `sdl-config --version` reports 1.2.72, where real SDL 1.2
  ended at 1.2.15, and the binary links `libSDL2` and `libSDL3`. So the game
  already runs on SDL2 through a translation layer. The 0.5.0 port removes that
  layer rather than changing platform.

- 24 assets in `assets/` are no longer loaded by anything (`make verify` lists
  them). They are left in place pending a decision on what to keep.

Earlier releases claimed the PNG assets were corrupt and that `libpng` aborted
on them. That was not true: all 89 PNGs pass chunk-CRC and IEND validation, and
a headless boot emits no libpng warnings. `Niv1.png` does carry a 2px near-white
column on its left edge — an export artifact, now trimmed by the asset
generator — which may be what was originally seen.

## Controls

| | Player 1 | Player 2 |
|---|---|---|
| Move | ← → | K / M |
| Jump | Space or ↑ | J or O |
| Run | A / D | W / X |

`ESC` leaves the level and returns to the menu. On the result screen, `ENTER`,
`ESC`, `SPACE` or a click returns to the menu, as does a 4-second timeout.

Both players must stand in the exit beacon to complete the mission. If either
player's health reaches zero, the mission fails.

## Requirements

Debian/Ubuntu:

```bash
sudo apt-get update
sudo apt-get install build-essential libsdl1.2-dev libsdl-image1.2-dev \
                     libsdl-mixer1.2-dev libsdl-ttf2.0-dev
```

Fedora:

```bash
sudo dnf install gcc make SDL-devel SDL_image-devel SDL_mixer-devel SDL_ttf-devel
```

Regenerating placeholder art additionally needs Pillow (`pip install Pillow`).
The build itself does not.

## Build and run

```bash
make            # build ./pro
./pro           # must run from the repository root: asset paths are relative
```

The executable loads every asset by a relative path, so running it from
anywhere else will fail.

## Development

There is no unit-test suite. These targets are the safety net:

```bash
make check      # what CI runs: strict build + asset verification + smoke boot
make strict     # build with -Werror; the tree is warning-free and must stay so
make verify     # every asset path resolves case-sensitively; PNGs valid; sizes
                # match MANIFEST.tsv; backdrops large enough for their parallax
make smoke      # boot headless, reach the game loop, no asset-load failures
make asan       # AddressSanitizer + LeakSanitizer (see the MP3 note above)
```

`scripts/frame_probe.sh <dir>` captures rendered frames from level 1 headlessly
by temporarily instrumenting the source and restoring it. Comparing two runs
byte-for-byte is how the platform-wrapper and state-machine refactors were shown
not to change rendering.

`src/collision.c` and `src/enemy.c` have no dependency on a window or an event
loop, so they can be driven directly from a small C driver and asserted on. That
is how the physics and the enemy interaction were verified.

## Layout

```
include/  platform.h      the only SDL surface; swap its backend for the port
          game_state.h    state machine, game_ctx, game_assets
          collision.h     swept AABB resolution
          perso.h         player entity and movement constants
          enemy.h         patrolling enemies and contact damage
          hud.h           HUD layout constants
          audio.h         sound events
src/      platform_sdl12.c  SDL 1.2 backend
          game.c            main, lifecycle, loop, transitions
          state_*.c         one file per game state
          hud.c  audio.c  collision.c  enemy.c  perso.c  menu.c
scripts/  gen_placeholder_assets.py  verify_assets.py  smoke_boot.sh
          frame_probe.sh
assets/   MANIFEST.tsv records every generated asset's required dimensions
```
